# Автоматизация Техник

В меню `⋮` карточки Rote переключитесь на «Автоматизация». Встроенный JavaScript редактируется в редакторе CodeMirror и выполняется первым. Затем выполняются привязанные Macro в порядке добавления. Каждый шаг запускается после создания карточки чата; ошибка шага записывается в консоль и не отменяет действие или остальные шаги.

Активный ГМ проверяет применение Техники и передаёт код на клиент пользователя, который совершил действие. Скрипт и привязанные Macro выполняются с его обычными правами: `game.user` и `canvas` относятся к нему. Права на исходные Macro и Item не изменяются. Если активного ГМа нет, бросок и Simple-действие создают результат и карточку, а автоматизация пропускается.

Для передачи кода ГМ временно записывает пакет в системный флаг карточки чата. Клиент принимает его только после обновления документа активным ГМом, затем флаг удаляется. Пока пакет существует, его содержимое может прочитать любой клиент, которому видна карточка. Нельзя рассчитывать на секретность исходного кода. Если пользователь может запустить исходный Macro, он выполняется как обычно. Иначе создаётся временный локальный документ; код, который обращается к `this.uuid`, `this.id` или ищет исходный Macro в `game.macros`, может вести себя иначе.

Встроенный скрипт получает параметры `context` и `api`. В привязанном Macro они доступны как `event.roteContext` и `event.roteApi`.

| Поле `context` | Значение |
| --- | --- |
| `mode` | `"roll"`, `"simple"` или `"campNoRoll"` |
| `rollType` | `"quick"`, `"tracked"`, `"reaction"` или `"simple"` |
| `outcome` | `"failure"`, `"consequence"`, `"success"`; для лагерного действия без кубиков `"success"` |
| `isCampAction` | Было ли это лагерное действие |
| `totalPower` | Сила броска, если применима |
| `actorId`, `roteId`, `roteUuid`, `roteName` | Персонаж и Техника |
| `initiatorId` | Пользователь, совершивший действие |
| `sceneId`, `tokenId`, `targetIds` | Сцена, токен и цели на момент действия |
| `rollId`, `messageId` | Идентификаторы действия и карточки чата |

`api.getActor()`, `api.getRote()` и `api.getMessage()` возвращают доступные пользователю документы Foundry. Для переданной Техники без прав `api.getRote()` может вернуть `null`. Например:

```js
if (context.outcome === "success") {
  const actor = api.getActor();
  console.log(`${actor.name} применил ${context.roteName}`);
}
```

В `campNoRoll` механический результат для автоматизации — успех. Групповые броски пока не запускают автоматизацию Техник.

В окне «Техники» перетащите иконку на хотбар, чтобы создать макрос запуска с фиксированной командой. Если у игрока нет права создавать скриптовые Macro, эту команду создаёт активный ГМ после проверки владения персонажем.
