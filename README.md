## Welcome to Legend in the Mist

This is a system for playing the game **Legend in the Mist** in Foundry Virtual Tabletop.

**Legend in the Mist [RN]** is an unofficial adaptation of Legend in the Mist for Foundry VTT. The project is still under active development, so some features may change. Nevertheless, the system already provides everything needed for comfortable play, including tools for the Narrator and players, tag and status management, rolls, and partial automation.

## Features

- Character, Challenge, and Journey sheets.
- Fellowship tools for characters and the Narrator.
- Character creation through different methods, using Themebooks, Theme Kits, and Tropes.
- Guided character advancement, including Improvements, Theme replacement and evolution, and Promise Fulfillment.
- Story Themes as world items or character items.
- Tag and Status management, including shared tags.
- Might and Limits support.
- Text enrichers for interactive Tags and Statuses in sheets, journals, and chat.
- Drag-and-drop Tags and Statuses between supported sheets, tokens, journals, Tag Manager and chat.
- Quick, Tracked, Reaction, and Sacrifice rolls, plus camp and group actions.
- Roll assistance with automatic Power calculation, tag scratching, and Improve marks from invoked weakness tags.
- Token HUD controls for quick management of Tags and Statuses on multiple tokens.
- Active Fellowship and Story Profile selection for managing multiple groups in one world.
- Customizable rules reference pages.
- Configurable illustrations for selected actors and items.
- Rotes linked to tags, with a dedicated Rotes window and chat cards.
- Rote automation with scripts and linked macros.

See the [Rote scripting API](docs/rote-api.md) for the context and helpers available to automation.
